# MSIX Asset Files

This directory contains asset files required for the MSIX package. These are placeholder files and should be replaced with proper Kiwix branding:

- **StoreLogo.png** (50x50) - Used in the Microsoft Store
- **Square44x44Logo.png** (44x44) - App list icon and taskbar
- **Square150x150Logo.png** (150x150) - Start menu tile
- **Wide310x150Logo.png** (310x150) - Wide Start menu tile

All images should be in PNG format with transparent backgrounds where appropriate.

## Creating Proper Assets

1. Use the official Kiwix logo and branding
2. Ensure proper resolution for each asset size
3. Test visibility on both light and dark backgrounds
4. Consider Windows design guidelines for best results

## Fallback

If proper assets are not available, the build process will generate simple colored squares as placeholders.
